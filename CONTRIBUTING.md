# Contributing

1. Create a branch for each task, for example `feature/image-preprocessing` or `feature/sentiment-task-1`.
2. Keep reusable Python code in `src/` and experiments in the relevant notebook.
3. Clear notebook outputs before committing.
4. Do not commit datasets, credentials, or model weights.
5. Open a pull request with a short description and relevant validation.
6. Add dependencies to `requirements.txt` when needed.
